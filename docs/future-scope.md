# Future Scope — UniGuide AI

1. **OCR Document Verification**: Automatic optical character recognition for reading marks directly from uploaded 10th/12th/Degree marksheets.
2. **Real-time Live Chat with College Counselors**: WebSockets-enabled live chat between prospective students and university admission representatives.
3. **Automated Application Filing Integration**: Direct API integration with centralized state university portals (such as NIMCET / CUET portals) to auto-submit applications.
4. **Push Notifications & SMS Alerts**: Integration with Twilio/Firebase for real-time mobile push notifications regarding upcoming counseling deadlines and merit list releases.
5. **Multi-lingual AI Chatbot**: Expanding Gemini prompt translation for regional Indian languages (Hindi, Punjabi, Tamil, etc.).
